# Charaktere

Gespeicherte Comic- und Anime-Figuren für Bilder. Jede Figur hat einen eigenen Ordner mit einem `CHARAKTER.md`.
Darin stehen das verbindliche Aussehen, Stil-Vorlagen und fertige Prompts für Grok.

| Name | Ordner | Kurzbeschreibung |
|---|---|---|
| **Kai** | [`kai/`](kai/CHARAKTER.md) | massiver Bodybuilder, honigblonde Tolle mit Skin-Fade, hellblaue Augen, Tattoo am rechten Unterarm |

## So funktioniert's

Sag einfach: **„Mach ein Bild mit Kai, wie er …“**.
Du bekommst dann einen fertigen Prompt aus Stil, Szene und Charakter-Baustein, den du in Grok einfügst.
Lade dazu dein gespeichertes **Kai-Master-Bild** als Referenz mit hoch.
